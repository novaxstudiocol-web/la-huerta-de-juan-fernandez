# La Huerta De Juan Fernández — Floristería Madrid

Página web profesional para la floristería **La Huerta De Juan Fernández**, ubicada en la Plaza Tirso de Molina, Kiosco #5, Madrid.

---

## Cómo personalizar tu página

### 1. Subir el Logo

Coloca tu archivo de logo en:

```
images/logo/logo.png
```

- **Formatos aceptados:** `.png`, `.webp`, `.jpg`, `.svg`
- **Tamaño recomendado:** 400 × 200 px (fondo transparente)
- Si no hay imagen, se muestra el nombre de la floristería como texto elegante

### 2. Subir el Banner

Coloca tu imagen de banner en:

```
images/banner/banner.jpg
```

- **Formatos aceptados:** `.jpg`, `.webp`, `.png`
- **Tamaño recomendado:** 1920 × 800 px
- Si no hay imagen, se muestra un fondo verde elegante con gradiente

### 3. Imágenes de Productos (2 por flor)

Cada producto tiene **dos imágenes**:
- `nombre-1.webp` → imagen principal
- `nombre-2.webp` → imagen que aparece al pasar el ratón (hover)

Coloca tus imágenes en la carpeta `images/productos/` con estos nombres exactos:

## Estructura de carpetas

```
la-huerta-de-juan-fernandez/
├── index.html
├── README.md
└── images/
    ├── logo/
    │   └── logo.png          ← TU LOGO aquí
    ├── banner/
    │   └── banner.jpg        ← TU BANNER aquí
    └── productos/
        ├── tuya-1.webp       ← imagen 1 Tuya
        ├── tuya-2.webp       ← imagen 2 Tuya (hover)
        ├── paniculata-1.webp
        ├── paniculata-2.webp
        └── ...               (2 imágenes por cada producto)
```

## Formatos de imagen recomendados

| Uso | Formato | Tamaño |
|---|---|---|
| Logo | PNG con fondo transparente | 400 × 200 px |
| Banner | JPG o WebP | 1920 × 800 px |
| Productos | WebP (mejor calidad/peso) | 600 × 750 px |

> **Consejo:** Usa formato `.webp` para los productos — carga más rápido y se ve mejor.
